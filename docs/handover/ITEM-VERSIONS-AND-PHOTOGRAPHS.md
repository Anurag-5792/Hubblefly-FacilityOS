# Item Master — Versions and photographs

**Document status: DRAFT — FEATURE NOT YET OPERATIONALLY QUALIFIED.**

## Intended capability

Each inventory item has an identifiable product version. Every current, historical or retired version must have an approved primary photograph. Additional views may include the front, side, rear, identification label and distinguishing details. The photos must identify the selected version, not merely another version of the same item.

## Intended operator workflow

1. Select the legal entity and the inventory item in Item Master, then select the exact product version.
2. Review whether that version already has an approved primary photograph. Check that the picture shows the correct physical variant and identifying labels.
3. Where permitted, submit the primary and additional views for review. Confirm that the images are authorized for HFT use and correspond to that version.
4. An authorized reviewer checks identity, image clarity, use rights and correct version association before accepting the photographs.
5. Confirm that all current and historical product versions show their own valid primary images. Missing or rejected images remain visibly incomplete and must not be represented as verified.

## Exceptions and protection

A photograph for an earlier variant cannot be automatically substituted for a later variant. Replacing an image does not delete the previous approved record or erase its history. Operators must not infer a version or accept an image solely from a filename. Access to view, add, replace and approve media follows assigned permissions.

**Current limitation:** Upload, review, durable storage, and version-gallery functionality are not yet qualified for live use. This document becomes an operational guide only after the corresponding features pass acceptance and the document is approved.


## Item version gallery — draft operator procedure

**Status: NOT YET QUALIFIED FOR LIVE USE.**

Once separately accepted, an authorized operator can open Stores, then Item
Master, select the exact item, and open **View all product versions**. After
selecting an approved company/site/warehouse scope, the complete version
register should show each current and historical product version separately.

Select a version to inspect its verified PRIMARY photograph and optional
front, side, rear, label or detail views. A missing primary photograph is
not the same as one awaiting verification. If an image cannot be retrieved,
do not treat a metadata approval as proof that the actual image is available.

Image uploads, independent approval, replacement and recovery remain
unavailable for live operations. Never use another item's or version's
photo as a substitute, even if labels or filenames look similar.
