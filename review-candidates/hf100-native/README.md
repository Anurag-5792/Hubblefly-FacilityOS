# HF100 native integration candidate

The original HF100 source and frozen SQL are unchanged. This branch contains the tested native lexer and a private orchestration integration module. It does not provide an unguarded SQL executor or public apply CLI. The authenticated deployment adapter supplies exact provider/GitHub/Drive operations; do not export connector tokens. The existing owner signature, private control/receipt custody, fixed one-time claim, independent postflight and no-retry semantics remain mandatory. Native recovery is an explicit changed-method contract using a pre-claim snapshot and isolated restore, not a portable encrypted backup. No whole-branch rewind or stock/identity activation is admitted. The native method's authorization, actual connector bridge and final recovery pin require disposition before retained mutation. Previous cloud DDL/recovery qualification is separate from this integrated source qualification.
